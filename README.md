# CodeAlpha Task Automation — JPG File Organizer

A Python script that moves `.jpg` and `.jpeg` images from a source folder into a destination folder.

## Features
- Checks whether the source folder exists.
- Creates the destination folder if needed.
- Moves JPG/JPEG files.
- Avoids overwriting files with the same name.

## Requirements
- Python 3
- No external packages required.

## Run
```bash
python task_automation.py
```

When prompted, enter the source folder path and destination folder path. Test with a sample folder first and only move files you are comfortable reorganizing.

## Concepts
`pathlib`, `shutil`, functions, loops, conditions, and file handling.
